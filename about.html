Module E Bagrut Vocabulary

Written by Teacher Simon Halevi

Teacher Guide and Project Overview

I created this project as a practical teaching environment for the vocabulary component of the Module E Bagrut. This guide explains how I organized the database, why I divided and shuffled the material, and how the activities connect with the teacher resources and assessment system.

1. Curriculum alignment and database structure

I built the vocabulary database to match the Module E curriculum. The Ministry of Education organizes the required vocabulary into four main lists: A, B, C and D. I kept those four official list boundaries throughout the project so that teachers and students can work according to the structure of the curriculum.

I then divided each main list into three teaching subgroups: A1–A3, B1–B3, C1–C3 and D1–D3. These subgroup labels are internal teaching units, not CEFR levels. I created them to make the learning load manageable and to allow the material to be taught gradually, one lesson-sized section at a time.

2. Randomization within each list

I considered randomization important because a fixed alphabetical or source order can make repeated practice feel predictable. I therefore shuffled the entries randomly within each of the four main lists before dividing that list into its three subgroups.

The entries were never mixed across the A–D list boundaries. The randomization changes the learning sequence inside each list while preserving its curriculum classification. This gives students a more varied learning experience and encourages them to recognize each item independently of its original position.

3. Separate records for different grammatical roles

Some headwords can function in more than one grammatical role. When an entry has more than one relevant part of speech, I duplicate the headword as separate database records. For example, a word that can be both a noun and a verb appears once as a noun record and once as a verb record.

Each grammatical-role record is treated as an independent learning item, with its own part-of-speech label, meaning and usage example. These records are shuffled independently. This prevents one broad entry from hiding important differences in grammar and meaning, and it allows each use of the word to be taught and tested separately.

4. Learner-friendly definitions and meaning support

For every learning record, I select the clearest form of meaning support. In most cases, this is a short definition written in simple English. When a simple synonym or a small group of synonyms gives a clearer explanation, I use those words instead of a longer definition.

For broad category words, examples may communicate the meaning more effectively than an abstract definition. In those cases, I use boundary examples in place of the definition—for example, familiar members of the category that show what the word includes. The target word itself is not used to define itself, and the explanatory language is kept at A2 level or below.

5. Teacher slide presentations

A teacher slide presentation will be supplied for every subgroup. Each presentation will follow the same vocabulary records used in its online activity, allowing the teacher to introduce, explain, review and practise the items in class before or alongside independent student work.

6. Bagrut-compatible tests, answer keys and scoring

The test structure is designed to correspond fully to the structure of the vocabulary questions in the Module E Bagrut examination.

Every subgroup will have a multi-version test set containing approximately thirty-five different versions. This makes it possible to assess the same vocabulary group repeatedly or to give students different versions while keeping the tested content and level consistent.

Each version will have its own separate answer key. A scoring software tool will receive the version number and the student's answers, select the correct key for that version, and calculate the score automatically.

7. Suggested teaching sequence

  1. Introduce one subgroup with its teacher slide presentation.
  2. Use the online activity for guided practice, homework or review.
  3. Repeat selected items according to the needs of the class.
  4. Administer one of the Bagrut-compatible test versions.
  5. Use the matching answer key or scoring tool to calculate the result.
