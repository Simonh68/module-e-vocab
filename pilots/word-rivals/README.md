# WORD RIVALS — פיילוט Band III, גרסה 0.1.0

**שני תלמידים מתחרים על לוח מילים משותף. זהו אב־טיפוס למשחק ולבדיקה, לא מבחן רמה ולא מוצר שפורסם.**

## הפעלה מיידית — שני שחקנים באותו מכשיר

פותחים את `demo.html` בדפדפן ובוחרים **שניים באותו מכשיר**. השחקנים מחליפים תורות; הממשק מציין למי התור. הקובץ עצמאי, ללא התקנה וללא נכסים חיצוניים. אין בו חיבור בין מכשירים. רענון או סגירה מאפסים את המשחק. סביבת הבדיקה אפשרה בדיקת הממשק מתוכן HTML מקומי, אך חסמה ניווט לכתובות מקומיות; פתיחת קובץ רגילה בטלפון פיזי טרם נבדקה.

## חוקי הפיילוט

- 16 מילים מאוצר המילים המאומת של Band III; שישה תורות לכל שחקן.
- בכל תור בוחרים אחד משלושה רמזים באנגלית: מילה אחת או קשר בין שתי מילים. אחרי הבחירה הרמז ננעל.
- הצלחה כובשת את המשבצות המתאימות, גם כשהן שייכות ליריב. מהלך כפול דורש ששתי המילים יהיו נכונות; כישלון אינו מוחק שטח שכבר נכבש.
- כל משבצת בבעלות השחקן שווה נקודה; שורה או עמודה מלאות מוסיפות שתי נקודות. בסוף מנצח בעל הניקוד הגבוה; תיקו אפשרי. אין נקודות על מהירות.
- לאחר המהלך מוצגים פירוש ודוגמה. בסיום מוצג לוח חזרה על המילים, ויש אפשרות למשחק נוסף עם החלפת השחקן הפותח.

מנגנון הניקוד ומספר התורות הם כללי פיילוט לבדיקה, לא איזון שהוכח במחקר. אין טענה שהמשחק משפר למידה או יוצר מעורבות לפני בדיקה עם תלמידים. **איזון בין רמות שונות נדחה ואינו מופעל כאן.**

## חיבור שני מכשירים — שרת פיתוח, עדיין ללא פריסה ציבורית

נדרש Node.js 22. אין חבילות צד שלישי ואין צורך ב־`npm install`.

```sh
node build.cjs
npm test
node server.cjs
```

השרת נפתח ב־`http://127.0.0.1:8787`. לבדיקה במחשב יחיד משתמשים בשני פרופילי דפדפן נפרדים, למשל חלון רגיל וחלון פרטי. יוצר החדר מקבל קוד; השחקן השני מצטרף בקוד. שני חלונות באותו פרופיל חולקים זהות זמנית ואינם שני שחקנים.

בדיקה ברשת מקומית מהימנה אפשרית באמצעות `HOST=0.0.0.0 node server.cjs`, ואז גלישה משני מכשירים לכתובת הרשת המקומית של המחשב. אין לחשוף שרת HTTP זה לאינטרנט ואין לבצע פתיחת פורטים בנתב. תצורת הרשת, חומת האש וטלפונים פיזיים לא נבדקו בסביבה הנוכחית.

השרת מנהל את התורות, התשובות והניקוד. בקשות השחקנים נשלחות ב־POST והעדכונים מופצים ב־Server-Sent Events. אין הכרעת מהירות. ניתוק עוצר פעולות בלי לאבד תור; החיבור יכול להתחדש באותה עוגייה כל עוד החדר בתוקף. משחק חוזר דורש הסכמה משני השחקנים. מזהה משחק וגרסת מצב מונעים שימוש חוזר במהלכים ישנים.

**אין כאן עדיין מתאם פריסה ל־Cloudflare Durable Objects או שילוב ב־Sites.** שרת Node חד־תהליכי זה הוא סביבת ניסוי; הוא אינו ממשק מוכן ל־Workers. לפני פריסה נדרשים מתאם אירוח מאושר, HTTPS, אבטחת עוגייה תחת תיווך, טיפול במכסות/עומס, ובדיקת שני טלפונים דרך רשתות שונות. אין לפרסם את מראת דף הבית הישנה כדי לשלב את המשחק.

## פרטיות ושמע

אין שדות שם, אימייל, צ׳אט, תשובות מוקלדות או הקלטות; אין אנליטיקה, פרופיל, טביעת דפדפן או ציוני תלמידים קבועים. במצב המקוון בלבד יש עוגיית השתתפות אקראית וקצרת־חיים לכל חדר, ומצב המשחק נשמר בזיכרון השרת. נשלחים קוד רמז ומזהי משבצות, לא טקסט תשובה חופשי. מזהי ההשתתפות אינם מוצגים בקישור החדר. נתוני משחק אינם נשלחים למורה.

חדר פג אחרי 30 דקות ללא פעולת משחק או לכל היותר שעתיים, ונמחק בבקשה הבאה או במחזור הניקוי הקרוב (עד דקה נוספת). הפעלה מחדש של השרת מוחקת את כל החדרים. עוגיית החדר מוגבלת לשעתיים; אחרי מחיקת החדר אין לה תוקף שרת. מגבלות אבטחה אלה אינן תחליף לבדיקת פרטיות ואבטחה לפני פריסה ציבורית.

השמעה זמינה רק אם הדפדפן מספק קול מקומי המוגדר באנגלית אמריקאית. אין מעבר שקט לשירות קול מרוחק. כאשר אין קול מתאים מוצגת הודעה, והמשחק ממשיך בלי שמע. השמעה נעצרת כשהעמוד מוסתר. איכות הקול במכשירים פיזיים טרם נבדקה.

## מה נבדק

- **19/19 בדיקות Node עברו**: מנוע, מקור/כיסוי מזהים, מניעת תשובות חשופות, כיבוש/כיבוש חוזר, ניקוד, מניעת מהלכים כפולים ושגויים, ושוויון מספר תורות.
- בתוך בדיקות המנוע הורצו **100 משחקים מלאים מדומים**; אין זו בדיקה עם 100 תלמידים.
- בדיקות HTTP/SSE עם שתי ישויות התחברות עצמאיות: חדר, משחק מלא, ניתוק וחיבור מחדש, סיום, אישור משחק חוזר, דחיית מהלך ממשחק קודם, תפוגה ודחיית גישה לא מורשית.
- ממשק Chromium מתוכן HTML מקומי: 12 תורות, משוב, סיום, חזרה על 16 מילים, משחק חוזר; תצוגה ברוחב 390 פיקסלים ללא גלילה אופקית. אין שגיאות JavaScript שנקלטו בבדיקה.
- בדיקת שני דפדפנים מול השרת דרך ניווט HTTP וטלפונים פיזיים **לא הושלמה**: סביבת הדפדפן חסמה ניווט לשרת המקומי במדיניות מנהל. לא בוצעה עקיפה.

פלט הבדיקות וצילומי הממשק בחבילת העבודה נמצאים בתיקיית `qa`. בדיקת הדפדפן האופציונלית דורשת Python, Playwright ו־Chromium מותקנים; אלה אינם תלות של המשחק עצמו.
