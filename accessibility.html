Site policy

Accessibility Statement

This learning application is designed and maintained so that students and teachers can use it on different devices and with common assistive technologies.

Accessibility status

The site has been updated with the aim of meeting the Israeli Standard 5568 requirements at level AA, based on the Web Content Accessibility Guidelines (WCAG) 2.0, and the Israeli Equal Rights for Persons with Disabilities (Service Accessibility Adjustments) Regulations, 2013.

A formal certification by an external accessibility specialist is not claimed. Accessibility is treated as an ongoing process, and reported problems will be reviewed and corrected where reasonably possible.

Accessibility features

  • Semantic page titles, headings, navigation and main-content landmarks.
  • A consistent Home control on every vocabulary activity.
  • Skip links and clearly visible keyboard focus indicators.
  • Keyboard-operable Play, Copy link, pronunciation, card-flip and navigation controls.
  • Screen-reader status messages for the current card and displayed side.
  • Correct language and text direction for English and Hebrew content.
  • Responsive layouts that support phones, tablets, computers and browser zoom.
  • Reduced animation when the device requests reduced motion.
  • No flashing content, advertising, timed questions or time limits.

Using the activities

Use Tab and Shift + Tab to move between controls, and Enter or Space to activate a focused button or link. The Previous and Next buttons move between cards. The Show answer button flips the current card. Left and Right Arrow keys also move between cards.

The pronunciation feature uses the speech engine installed in the user’s browser or device. It is an optional aid; all essential learning information is also presented as text.

Documents and known limitations

Archived Ministry source spreadsheets are provided for source transparency. Spreadsheet accessibility may vary by program and device. The essential vocabulary learning content is available in the HTML activities. An alternative accessible format may be requested by email.

Automated static checks cannot replace testing by every assistive technology. If a page, control or document is difficult to use, please report the exact page, device, browser and problem.
